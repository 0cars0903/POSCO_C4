# 이차전지 화성공정 불량률 영향인자 도출

> **POSCO 청년 AI BigData Academy 20기 최종 프로젝트 — 우수상 수상**

## 핵심 성과
- 불량률 **2.38% → 0.62%** (74% 감소, 시뮬레이션)
- 연간 절감 효과: 약 **15억원** 추정
- 통계 검증: ANOVA + Paired t-test (p < 0.05)
- 최적 조건 도출: Decision Tree로 **26.5 ~ 31.5°C** 구간 확정

## 파일
| 파일 | 설명 |
|------|------|

## 분석 파이프라인
1. EDA — Rack 위치별 온도 분포 Heatmap 시각화
2. 가설 수립 — Rack 위치 × 온도 편차 → 불량률 관계
3. ANOVA 검증 — 정규성(Shapiro-Wilk) + 등분산성(Levene) + 독립성 확인
4. Paired t-test — 그룹 간 유의차 확인
5. Decision Tree — 최적 온도 구간 26.5~31.5°C 도출
6. 시뮬레이션 — 개선 조건 적용 시 불량률 74% 감소 추정
