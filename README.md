## 🏆 최종 프로젝트 (우수상)

### [이차전지 화성공정 불량률 영향인자 도출](./이차전지_화성공정_최종프로젝트/)

| 항목 | 내용 |
|------|------|
| **수상** | 우수상 |
| **핵심 성과** | 불량률 2.38% → 0.62% (**74% 감소**, 시뮬레이션) · 연간 **15억원** 절감 가능성 |
| **방법론** | ANOVA + Paired t-test (통계 검증) → Decision Tree (최적 구간 도출) → Heatmap 시각화 |
| **핵심 발견** | Rack 위치별 온도 편차(26.5~31.5°C 구간)가 불량률의 핵심 원인 |
